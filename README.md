# Трекер привычки — 21 день

Простой одностраничный трекер для формирования одной привычки за 21 день. Работает полностью в браузере, без сервера и регистрации.

## Возможности

- приветственный лендинг с описанием подхода;
- выбор своей привычки или готового примера;
- календарь на 21 день с отметками выполнения;
- кольцо прогресса и статистика;
- навигация по неделям;
- продление на 7 дней после завершения базового цикла;
- сохранение прогресса в `localStorage`.

## Быстрый старт

1. Склонируйте или скачайте репозиторий.
2. Откройте `index.html` в браузере — двойным кликом или через локальный сервер.

### Локальный сервер (опционально)

```bash
# Python
python -m http.server 8080

# Node.js (npx)
npx serve .
```

После запуска откройте `http://localhost:8080`.

## Как пользоваться

1. На главной странице нажмите **«Начать отслеживание»**.
2. Введите одну привычку или выберите пример.
3. Каждый день отмечайте выполнение галочкой.
4. По завершении 21 дня решите: начать новую привычку или продолжить ещё 7 дней.
